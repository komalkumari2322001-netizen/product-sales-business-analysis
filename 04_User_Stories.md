# 👤 User Stories

## 1. What is a User Story?
A user story describes a requirement from the user's perspective. It answers:
- **Who** needs it? (Role)
- **What** do they need? (Feature)
- **Why** do they need it? (Benefit)

---

## 2. Sales & Revenue User Stories

### US-01: Revenue Overview
- **As a:** Management Executive
- **I want to:** View total sales, total orders, and average order value in one place
- **So that:** I can quickly understand overall business growth.
- **Acceptance Criteria:** Dashboard shows top summary cards for Total Revenue, Total Orders, and Average Order Value.

### US-02: Regional Performance
- **As a:** Sales Manager
- **I want to:** Compare sales and order counts across different regions
- **So that:** I can find underperforming regions and improve local sales.
- **Acceptance Criteria:** A map or bar chart showing sales performance by region with simple dropdown filters.

---

## 3. Product & Return User Stories

### US-03: High Return Products
- **As a:** Product Manager
- **I want to:** See which products have high return rates and read return reasons
- **So that:** I can fix quality issues or update product descriptions.
- **Acceptance Criteria:** A table listing return rate percentage and top return reasons per product.

### US-04: Discount Impact
- **As a:** Marketing Manager
- **I want to:** See how discounts affect total sales and profit margins
- **So that:** I can create profitable discount strategies without losing money.
- **Acceptance Criteria:** A chart comparing discount levels against sales volume and profit.

---

## 4. Shipping & Operations User Stories

### US-05: Shipping Costs & Delivery Time
- **As an:** Operations Manager
- **I want to:** Track average delivery time and shipping costs by region
- **So that:** I can eliminate delivery delays and reduce shipping expenses.
- **Acceptance Criteria:** Visuals showing average delivery days and shipping costs per courier or region.
